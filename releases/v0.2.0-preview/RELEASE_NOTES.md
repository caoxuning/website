# cartabio v0.2.0-preview

Review release, 2026-09-25. This is a deployable static Vite build of the independent cartabio concept site. Extract the attached ZIP at a web root, keeping `index.html` at `/`. Asset URLs assume root-path hosting.

## Changes since v0.1.0-preview

- Promoted the continuous narrative to `/`; preserved the previous homepage at `/legacy.html`.
- Connected the company proposition, cooperation directions, delivery path and SAFE/AI concepts through one interactive Three.js tissue view with scroll-led typography.
- Reworked the historical-image section around a customer's research question. The image status remains visible, with detailed source limits in its dialog.
- Added a complete team, consultation and footer ending. Consultation still downloads a local draft and does not submit data.
- Audited page copy, navigation and dialogs; see `docs/content-audit.md` and `docs/content-provenance.md` in the source repository.

## Review boundary

This is not a cleared public corporate launch. Confirm service scope and deliverables, fixed-sample SAFE validation, historical image identity/permissions, current team roles/portrait permissions and official contact details before publication. Procedural visuals and ROI selections are illustrations, not experimental results or validated AI output.

## Verification

Unit tests, homepage/legacy browser flows, four-viewport story/canvas checks, content-provenance checks and the production build passed before packaging. The ZIP contains 23 files, each verified byte-for-byte against the build output. It is the build output, not source code.
