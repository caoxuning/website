# cartabio v0.1.0-preview

Initial review release, 2026-09-24. This is a static Vite build of the independent cartabio concept site. The ZIP contents can be served from a web root; `index.html` must remain at the root. Asset URLs assume root-path hosting.

## Included

- Responsive company, solution, delivery, technology, research and team sections.
- Original interactive Three.js tissue illustrations and matching static first frames.
- Native continuous scrolling, accessible navigation and local consultation-draft download.

## Release boundary

- This package is for review, not an approved public corporate launch.
- The consultation form does not send or store information on a server.
- Historical team names/roles, case imagery, scientific provenance, asset publication rights and current contact details require company confirmation before public deployment.
- Procedural tissue imagery and analysis selections are illustrative, not experimental results or validated AI output.

## Verification

Built with `npm.cmd run build` from project version `0.1.0`. Unit, continuous browser, responsive layout and production-build smoke checks are recorded in `docs/verification.md`. The release archive SHA-256 is reported beside the download link at handoff.
